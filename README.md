BOLA_MARKET – Java OOP Shopping System

Overview

BOLA_MARKET is a console-based shopping system developed using Java. The project demonstrates object-oriented programming principles through a simple shopping workflow, including product management, shopping carts, orders, and payment methods.

Features

- Product Management: Represent and manage products.
- Shopping Cart: Organize cart items before placing an order.
- Order Management: Represent customer orders.
- Multiple Payment Methods: Includes cash on delivery, credit card payment, and wallet payment.
- Custom Exceptions: Handles specific cases such as insufficient cash and out-of-stock products.
- Admin and User Roles: Separate classes for administrative and customer-related functionality.

Technologies

- Java
- Object-Oriented Programming (OOP)
- Git and GitHub
- IntelliJ IDEA

OOP Concepts

The project structure demonstrates object-oriented design through classes and relationships between products, users, carts, orders, and payment methods. Payment-related classes and custom exceptions illustrate ways to organize application logic.

Project Structure

- "Admin.java" – Administrative functionality
- "User.java" – User-related functionality
- "Product.java" – Product representation
- "Cart.java" and "CartItem.java" – Shopping cart functionality
- "Order.java" – Order representation
- "PaymentMethod.java" – Payment method abstraction
- "CashOnDelivery.java", "CreditCardPayment.java", and "WalletPayment.java" – Payment implementations
- "NotEnoughCashException.java" and "OutOfStockException.java" – Custom exceptions
- "Menu.java" – Console menu

How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a compatible JDK is configured.
4. Compile the Java source files.
5. Run the class containing the "main" method.

Project Type

This is an educational Java console application focused on object-oriented programming. It does not currently use a database or expose REST APIs.
